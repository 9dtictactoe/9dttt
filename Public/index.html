About the Library

The 9DTTT Game Library is a growing collection of strategic, accessible, and fun family games. All games are designed with:

  • ✅ Full keyboard navigation support
  • ✅ Screen reader compatibility
  • ✅ Mobile-responsive design
  • ✅ High contrast mode support
  • ✅ Reduced motion options
  • 🎮 Bluetooth/USB Gamepad support (up to 4 players!)
  • 💬 In-game chat with quick messages and emojis

More games coming soon! Each game is built with clean, modular code for easy maintenance and expansion.
